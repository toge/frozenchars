# frozenchars 将来機能候補

このセッションで実装した内容に続いて、今後検討したい候補をまとめる。

## 9. 文字列比較・検索の強化
- `contains_ci` / `starts_with_ci` / `ends_with_ci` の追加
- 大文字小文字を区別しない比較を `FrozenString` ベースで提供
- UTF-8 / Unicode 文字列に対する比較を検討

## 10. 文字列フォーマット・挿入支援
- `format_with` 風のテンプレート展開
- `{name}` / `{value}` 形式の簡易置換
- 既存の `format` 系 API と揃えた静的な構築方法を検討
