# 9〜13 の実装用プロンプト

以下の内容をそのまま実装エージェントに渡せるようにしたプロンプトです。

---

あなたは `frozenchars` リポジトリの C++23 ヘッダオンリーライブラリに対して、機能追加を行う実装担当です。

## 目的
`FrozenString<N>` ベースの既存 API パターンに合わせて、以下の機能を実装してください。

- 9. 大文字小文字を無視した文字列比較・検索ヘルパー
  - `contains_ci`
  - `starts_with_ci`
  - `ends_with_ci`
- 10. テンプレート置換による簡易フォーマット支援
  - `format_with` もしくは `interpolate`
  - `{name}` / `{value}` 形式のプレースホルダーを扱う
- 11. 前後空白除去ヘルパー
  - `trim`
  - `trim_left`
  - `trim_right`
- 12. 単語・トークン分割ヘルパー
  - `split_words` もしくは `tokenize`
  - 空白区切り・複数空白・改行を扱えること
- 13. C スタイル文字列エスケープ/アンエスケープ
  - `escape_c`
  - `unescape_c`
  - 既存の実装がある場合はそれに合わせて統一すること

## 前提
- プロジェクトはヘッダオンリー C++23 ライブラリです。
- `FrozenString<N>` を中心に設計されており、可能な限り `consteval` / `constexpr` で実装してください。
- 既存の命名規則・スタイルに合わせてください。
  - クラス・変数・メンバ: `lower_case`
  - 関数: `camelBack`
  - 定数・constexpr 変数: `UPPER_CASE`
- コメントは日本語 Doxygen 形式で付けてください。
- 変更は必要最小限にし、既存 API と整合性を保ってください。

## 実装方針
1. まず対応するテストを追加してください。
   - `test/` 配下に新規または既存テストファイルに追加してください。
   - 追加したテストが未実装でもコンパイルエラーになる形にして、実装前の失敗を確認してください。
2. 実装は適切なヘッダに追加してください。
   - 文字列操作: `include/frozenchars/string_ops.hpp`
   - ケース変換: `include/frozenchars/case_conv.hpp`
   - エンコーディング/エスケープ: `include/frozenchars/encoding.hpp`
   - 必要に応じて `include/frozenchars/mod/*.hpp` から公開経路を確保してください。
3. 実装後はビルドとテストを実行してください。
   - `bash build.sh`
   - `bash test.sh`
4. 失敗した場合は修正し、最終的に全テストが通る状態にしてください。
5. 変更が必要な場合は README / CHANGELOG も更新してください。

## 受け入れ条件
- 追加した各機能に対するテストが通ること
- 既存テストが壊れていないこと
- `bash build.sh` と `bash test.sh` が成功すること
- 実装は既存のライブラリの API パターンに沿っていること

## 補足
- 13 は既存実装の有無に応じて統合してください。
- 実装の難しい部分は、まず最小構成で動く形を作り、必要に応じて拡張してください。
- もし API 形が既存の設計と衝突する場合は、まずその点を明示してから実装方針を確定してください。
